# Separation Process Design

Use this skill when the user asks for separation sequences, selective dissolution,
or process design for polymer mixtures.

## Workflow

1. Delegate to separation-engineer with full polymer list and any temperature constraints
2. Review the returned separation plan for completeness
3. If the user also wants cost or safety analysis, delegate sequentially to
   biosteam-analyst or safety-analyst with the separation results

## What to Include in the Task Description

- ALL polymers in the mixture (don't omit any)
- Temperature constraints or preferences
- Any solvents the user wants to include/exclude
- Whether they want single or multiple scheme options

## Quality Checks

- Every polymer in the mixture must appear in the separation sequence
- No solvent should be used above its boiling point
- Selectivity >= 5 for each separation step
