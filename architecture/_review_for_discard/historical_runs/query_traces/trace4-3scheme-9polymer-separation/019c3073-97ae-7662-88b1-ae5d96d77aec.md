## Key Observations

### Ordering shift
All 3 agent schemes dissolve EVOH first (step 1), whereas the paper dissolves it 6th. The agent found high EVOH selectivity in triethylamine and other polar solvents at low temperatures, making it an attractive first-removal target. The paper's ordering (PS -> PVC -> polyolefins -> EVOH -> nylons -> PET) was optimized via COSMO-RS selectivity calculations to avoid cross-contamination during the polyolefin steps.

### Scheme differentiation
The agent produced genuinely distinct schemes rather than trivial temperature variations:
- **Scheme 1** uses classical solvents (benzene, THF, cyclohexane, o-xylene, DMF, DMSO, ethylene glycol)
- **Scheme 2** favors high-boiling-point alternatives (dodecane for polyolefins, cyclohexanol for PA6, ethylene glycol for PA66) providing maximum thermal headroom
- **Scheme 3** uses a focused aromatic/polar strategy (toluene, p-xylene for multiple steps) and recovers PET as residue like the paper recovers PA66

### Solvent validity
All 27 solvent-temperature pairs across the 3 schemes operate below the solvent boiling point. Several steps operate close to the boiling point (3-7 C margin), which is acceptable for atmospheric dissolution with a reflux condenser.

### Cost of exploration
Generating 3 schemes required 1.57M tokens and 234s -- 12x the tokens and 3.4x the wall-clock time of the single-scheme Trace 3 (127K tokens, 69s). The separation-engineer subagent made 20 tool calls (hitting the patched limit) and exceeded the 200K token budget at 202K prompt tokens. The remaining ~1.37M tokens came from repeated LLM context accumulation across 54 messages.

### Benzene concern
Scheme 1 proposes benzene for PS dissolution. While thermodynamically valid, benzene is a known carcinogen (IARC Group 1). The paper uses toluene for PS, which is a safer aromatic alternative. The agent did not flag this safety concern because the safety-analyst subagent was not invoked (single-agent routing to separation-engineer only).
