# Architecture Review/Discard Candidates

This folder contains architecture artifacts moved out of the root directory
without deleting anything.

- `generated_media/`: generated root-level PNG/PDF/SVG diagrams and plots.
- `historical_runs/`: archived trace folders, old test results, and DP lattice
  sweep outputs.
- `benchmark_outputs/`: old benchmark/result JSON outputs.
- `legacy_plotting_scripts/`: scripts used to generate older architecture
  figures and benchmark plots.

The active architecture specs and harnesses remain in `architecture/`.
