## Key Findings

- Visualization selected-runtime behavior was the strongest area: solubility, DP state map, and separation tree plots produced files at the requested directories.
- BioSTEAM typed runtime has two gaps: user-facing success summaries omit requested metrics, and batch/multi-polymer BioSTEAM requests compile to a single simulation.
- Research/RAG queries can be preempted by selected typed-runtime intents when they contain HSP, BioSTEAM, TEA/LCA, or metric wording. Complex compiler-first gating needs a research/RAG exemption or intent priority fix.
- Patent search currently fails closed because live patent APIs are not configured; one patent query also surfaced an unawaited coroutine/RecursionError warning path.
- One fixed-temperature separation query did not hold the fixed 100 C constraint and returned higher solvent-specific temperatures.
